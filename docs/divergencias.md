# Divergences between documentation and behavior

Record of cases in which something documented (manual, names, earlier specification) diverges from what the original does, or in which the port does something differently from the original. The original wins.

Reviewed on 2026-10-18 against the code in `main` (each row checked in `engine/src`, `simant/src`, `data/` and tests): duplicate rows removed; resolved ones moved to the "Resolved" section, which stays as history. New sweep of the "Open" section on 2026-10-19: 7 rows that were resolved, or were already resolved in the code, moved to "Resolved" (full list A, `_KillAntLion(-1)`, left button in the loop, `_goStep*`, buttons of the two ribbons, window order in the yellow ant's animations, `_LastColonyPopR`).
