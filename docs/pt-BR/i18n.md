# Idiomas (frame de i18n)

Todo texto que **o próprio port** mostra passa por um frame de idiomas cujos dados ficam em
`data/idiomas/`, nunca no código. Os textos do SimAnt original (menus, diálogos, ajuda, mensagens
do jogo) não fazem parte dele: continuam vindo da instalação do usuário, que é em inglês.

Hoje:

| Contexto | Idiomas | O que cobre |
|---|---|---|
| `launcher` | `en`, `pt-BR` | a tela de opções de inicialização (`simant` sem opções ou `--launcher`) |
| `jogo` | `en` | tudo depois do launcher: mensagens em caixas e na faixa geradas pelo port, recusas das ações de mods, avisos de mods, título da janela, mensagens do console/log, `--help` e erros da linha de comando, erros da API Lua |

A infraestrutura já permite outro idioma no jogo: traduzir as chaves e acrescentar `"jogo"` aos
contextos daquele idioma no índice. Nenhuma mudança de código é necessária.

## Arquivos

```
data/idiomas/
  idiomas.json      índice: idiomas e os contextos em que podem ser escolhidos
  en.json           inglês (o idioma de reserva; completo)
  pt-BR.json        português do Brasil (por enquanto só o launcher)
```

### O índice: `idiomas.json`

```json
{
  "idiomas": {
    "en":    { "nome": "English",            "contextos": ["launcher", "jogo"] },
    "pt-BR": { "nome": "Português (Brasil)", "contextos": ["launcher"] }
  }
}
```

- A chave é o código do idioma (no estilo BCP 47: `en`, `pt-BR`, `es`, `de-AT`...).
- `nome`: o nome mostrado no seletor do launcher, escrito no próprio idioma.
- `contextos`: onde o idioma pode ser escolhido: `launcher` e/ou `jogo`.
- O índice é um objeto por código (não uma lista) para que um mod acrescente um idioma mesclando
  por chave, sem repetir os outros.
- O inglês está sempre disponível, mesmo fora do índice.

### Um arquivo de idioma: `<código>.json`

Objeto plano `"chave": "texto"`:

```json
{
  "_comentario": "chaves que começam com _ são comentários",
  "launcher.botao.jogar": "Jogar",
  "mods.script_desligado": "Mod {nome}: script desligado por erro"
}
```

- **Parâmetros**: `{nome}` é trocado pelo valor que o código (ou o script) passa com esse nome.
  Um `{nome}` sem valor fica como está. `{{` e `}}` são chaves literais.
- Chaves que começam com `_` são comentários. Valores que não são texto são ignorados.
- Texto em UTF-8. A fonte 8 × 8 do launcher cobre ASCII e Latin-1 (U+00A0–U+00FF: á, ã, ç, é,
  ê, ó, ô, ú, à, ü, ñ...); outros caracteres saem como `?`. O jogo usa as fontes do original.

### Grupos de chaves

| Prefixo | Onde |
|---|---|
| `launcher.*` | a tela do launcher |
| `cli.*` | linha de comando: erros e `cli.ajuda` (o texto do `--help`) |
| `programa.*` | mensagens do programa: caixa de erro fatal, log, configuração do launcher |
| `jogo.*` | textos do jogo gerados pelo port (título da janela, preferências, som, gravação) |
| `mods.*` | mensagens sobre mods: script desligado, recusas de ações (`mods.recusa.*`), dependências |
| `lua.*` | erros da API Lua (lidos por autores de mods no log) |
| `mod.<nome do mod>.*` | textos de um mod, trazidos pelo próprio mod |

## Reserva

Quando falta uma chave no idioma escolhido, vale o texto em inglês, e o log ganha um aviso por
chave (`i18n: 'chave' missing in pt-BR; using English`). Quando falta também em inglês, aparece a
própria chave (com um aviso). O inglês nunca fica sem uma chave do port: um teste
(`engine/tests/textos_traduzidos.rs`) confere que toda chave citada no código existe em `en.json`.

## Escolha do idioma

- **Launcher**: o seletor na faixa do título. Padrão: `--idioma CÓDIGO`, se dado; senão o `idioma`
  gravado em `launcher.json`; senão o idioma do sistema (código exato ou a mesma língua: `pt-PT`
  acha `pt-BR`); senão inglês. Escolher um idioma o grava em `launcher.json` na hora.
- **Jogo**: o mesmo pedido (`--idioma`, que o launcher põe na linha de comando, ou o idioma do
  sistema), mas só entre os idiomas do contexto `jogo`; hoje, sempre inglês.
- Idioma do sistema: no Windows, os idiomas de interface preferidos do usuário
  (`GetUserPreferredUILanguages`) e a localidade do usuário; nos outros, `LANGUAGE`, `LC_ALL`,
  `LC_MESSAGES` e `LANG`.

## Acrescentar um idioma

1. Copie `data/idiomas/en.json` para `data/idiomas/<código>.json` e traduza os valores (mantenha
   as chaves e os `{parâmetros}`). Chaves não traduzidas caem no inglês.
2. Acrescente o idioma a `data/idiomas/idiomas.json`, com o nome e os contextos.

Ou como mod: uma pasta de mod com

```
data/idiomas/idiomas.json   {"idiomas": {"es": {"nome": "Español", "contextos": ["jogo"]}}}
data/idiomas/es.json        {"jogo.erro.load": "Error al cargar: {erro}", ...}
```

Os arquivos de idioma dos mods são mesclados por chave sobre os do port (como todo `data/*.json`,
ver `docs/api-mods.md`), na ordem dos mods. Valem para o jogo; o launcher roda antes da escolha dos
mods e lê só o `data/idiomas/` do port.

## Textos de mods

Um mod traz as próprias chaves (`mod.<nome>.*`) em `data/idiomas/<código>.json` dentro do mod e as
lê em Lua (API de mods 0.43):

- `idioma()`: o código do idioma do jogo (`"en"`).
- `traduzir(chave, params)`: o texto de `chave` no idioma do jogo, com os parâmetros `{nome}` da
  tabela `params` (valores convertidos com `tostring`). Chave ausente cai no inglês e, depois, na
  própria chave.

Os mods de exemplo (`exemplos/mods/trapacas`, `exemplos/mods/exemplo-lua`) fazem isso, com os
textos em inglês e uma tradução em português como segundo exemplo.

## O que não é traduzido

- Os textos do jogo original (vêm da instalação do usuário).
- **Diagnósticos de desenvolvedor**: erros de arquivos originais corrompidos, tabelas de dados
  inválidas, invariantes internas e os rastros das opções de automação (`--ticks`, `--menu`,
  `--dialogo`...). Ficam em inglês direto no código, para quem está consertando dados ou código.
- Chaves de dados e nomes de opções (`--sem-som`, `ninho_preto`...): são identificadores.

Um teste (`engine/tests/textos_traduzidos.rs`) falha se um literal de texto do código fora dos
testes de `engine/src` ou `simant/src` parecer texto em português.

## Código

- `engine/src/idiomas.rs`: `Textos` (um idioma com a reserva em inglês), `Indice`, `escolher` (as
  regras da escolha), a tabela global do jogo (`atual`, `instalar`) e a macro
  `tr!("chave", nome = valor)`.
- `simant/src/idioma_sistema.rs`: os idiomas preferidos do sistema.
- `simant/src/launcher/`: o launcher tem o seu próprio `Textos` e o troca pelo seletor.
