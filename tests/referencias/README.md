## How to capture and compare

```
powershell -ExecutionPolicy Bypass -File tools\capturar_original.ps1 -Saida tests\referencias\capturas\NOME.png [-Espera 28] [-Cliques 'x,y;x,y']
cargo run -p simant -- --exportar-telas re_trabalho\telas_port
python tools\comparar_captura.py re_trabalho\telas_port\TELA.png tests\referencias\capturas\NOME.png --diff re_trabalho\diff.png
```

Warning: the script brings the DOSBox-X window to the front and, with `-Cliques`, moves the real mouse. The Windows 3.1 cursor inside the emulator moves relatively, so click coordinates are not reliable. Prefer waiting for the game's timings or using the keyboard. The screenshot is taken at 1:1 (`windowresolution = original` in the configuration). The game's client area starts at line 38 of the screenshot. The screenshots contain images from the game and **are not versioned** (they are in `.gitignore`).

When a case is observed: store the screenshot in `capturas/`, fill in the "Observed" column and, if there is a difference, record it in `docs/divergencias.md`.
